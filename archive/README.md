# Retired source archive

The active repository contains only the code and numerical records used by the
current manuscript. Superseded source snapshots are stored in
`retired_code_20260914/retired_sources.zip`, together with per-file SHA-256
checksums. They are retained for provenance and are not part of the installed
package or the current experiment workflow.

Historical experiment results, paper previews, and review-transfer bundles were
removed from the active Git tree. The current paper examples are retained under
`results/first_group/` and `results/paper_resampled_20260914/`.
