# Archived experiments

The active experiment scope is intentionally limited to three PDE families:

- `../chirp/`
- `../maxwell/`
- `../polyharmonic/`

The active formal result bundle is:

```text
../results/jsc_v2/
```

This archive keeps all other experiment material without deleting it:

| archive path | contents |
|---|---|
| `other_families/` | Helmholtz, variable-coefficient Helmholtz, Cahn–Hilliard, KdV, NLS, plate/beam, and core-method diagnostics |
| `results/` | pilots, boundary/PDE-weight searches, Mscale-5 sensitivity, single-seed controls, and other non-main result bundles |
| `scripts/` | non-formal runners used by the archived experiments |
| existing files in this directory | older historical oscillatory runners |

Nothing was deleted. The moves are tracked by Git and can be reversed if an
archived experiment is needed later. Archived paths are not part of the active
paper result inventory.
