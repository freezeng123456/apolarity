# Paired fixed-step learning-rate-decay experiment

User-requested follow-up to the ten-minute experiment. Preserve the existing
soliton KdV-gPINN equation, additive full loss, initial/boundary constraints,
400 training points per update, 128 constraint points, 4-layer width-128 MLP,
float32 eager PyTorch, Adam and seed 20260918. This is not a claim of full
STDE reproduction: neither the official implementation's extra loss square
nor its disabled boundary conditions is introduced.

Both methods train from identical initialization for exactly 10,000 updates.
At zero-based update k, lr = 0.001 * (1 - k / 10000). The first applied rate
is 0.001; the last applied rate is 1e-7; the schedule reaches zero after
update 10000. This matches update-count rather than wall-clock scheduling.
No ten-minute cap applies. Only schedule, stopping rule and assessment cadence
change relative to the preceding experiment.

Assess at steps 0, 50, ..., 10000 (201 assessments per method), using the
same fixed 400 points and an independent nested-JVP full-loss evaluator.
Save every assessment's model and optimizer state. Assessment does not draw
from the training sampler or update the optimizer. A regression test compares
two assessment cadences and requires bit-identical final model, optimizer,
and sampler states for both methods.

Single T4-B, sequential order shared_jet_linear then nested_jvp. Each formal
cell has a 4000-second safety timeout; completion requires all 10000 updates.
Primary plots: fixed loss versus step and measured wall time, with no smoothing.
Raw stochastic loss and solution relative L2 are supporting diagnostics.
Wall time includes periodic evaluations and checkpoints, excludes initial
assessment and final diagnostics. First threshold observations are only
resolved to the 50-update assessment cadence. Single paired seed only.
