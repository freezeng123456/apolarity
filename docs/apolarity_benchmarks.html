统一实验协议

计算域
默认 (-1,1)^d；NLS 为物理域 x∈[-5,5], t∈[0,π/2] 再归一化输入
配点
内点 n_int=4096；边界 n_bc=512（均匀随机重采样，每步固定一批）
优化
Adam lr=1e-3，余弦退火至 lr/10（lr_schedule=cosine）
预算
墙钟 600 s / run（脚本默认 80–120s，data 为 600s 正式跑）
重复
seeds=2（seed 0, 1）
深度
depth=4
宽度
所有架构使用字面宽度 --hidden（不做 √2 缩放）。正式 width study：实基线 hidden=128；complex_sinh 同时跑 h=64 与 h=128（两档复网夹住实基线参数量）
架构
complex_sinh, fourier, siren, mscale；omega0 / fourier_sigma 按算例频率匹配
参数量
n_params 中每个复权重计 2 个实 DOF；同宽度下 complex@128 的计数约为 siren@128 的约 2 倍。对照数据见各族 *_h64.* 与 *_h128.*
评估
8192 个均匀随机点的相对 L²：‖u−u*‖₂ / ‖u*‖₂
导数后端
jet 架构用 complex-Waring + Taylor jet；Cauchy 等 fallback 标为 autograd

网络架构与宽度对照

对比原则（见 experiments/README.md、variant_width）：一律使用字面宽度，不按参数量把实基线缩放到 √2·H。复权在 n_params 里按「实部+虚部」计 2 个自由度，故在相同 hidden 下复网络可调参数更多。width study 让 complex_sinh@64 与 complex_sinh@128 分别位于实基线 @128 的两侧；若 complex@64 ≈ complex@128，说明方法对宽度不敏感。

variant说明n_params（d=2, depth=4, hidden=128）
complex_sinh复值 sinh + holomorphic 频率初始化（主方法）；另跑 hidden=64 一档≈100k
fourierFourier features + tanh MLP，σ 随目标频率匹配≈66k
sirenSIREN (sin 激活)，ω₀ 匹配≈50k
mscale多尺度 DNN（多子网，参数量最大）≈150k

复值算例（NLS / Maxwell）中，实基线为 split-real RVPINN：两个独立的实网络分别拟合 Re u 与 Im u，各用同一字面宽度 H（不是单个 √2 放大的网络）。

本文结果表默认来自 *_h128.csv；*_h64.csv 为 complex_sinh 的窄网对照，见各 experiments/<族>/data/。

损失函数与历史格式

线性算例（run_linear_suite）

L = L_int + 100 · L_bc  (+ 1e-6 · Im(W)² 若复参数)

L_int = mean( ((Lu − f) / res_scale)² )
L_bc  = mean( (u − g)² )  + Navier 项（高阶 Δ^j u）

非线性 / 复值算例

  • Cahn–Hilliard：非线性项 Δ(u³)=3u²u_xx+6u(u_x)² 由单项偏导组装；BC 含 u, u_xx, (6阶) u_xxxx
  • NLS / Maxwell：复值残差模方；split-real 基线输出 (Re, Im) 两通道

历史 JSON

路径：experiments/<族>/data/<stem>_h128_history.json

每条记录：[elapsed_s, rel_L2_err, L_int]，约 40 个时间点均匀覆盖 600s。
