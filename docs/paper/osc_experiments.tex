\section{Numerical experiments on oscillatory and high-order PDEs}
\label{sec:osc}

We compare the proposed complex-parameter \(\sinh\) network with three
literature baselines: SIREN, a Fourier-feature PINN, and MscaleDNN.  Before any
measurement is admitted to this section, each baseline implementation must be
traced to a fixed upstream commit and pass the architecture and derivative
tests described in the repository's baseline audit.

\subsection{Shared protocol}
\label{sec:bm:protocol}

Protocol \texttt{jsc\_v2} uses a 1200-second wall-clock budget per
\((\text{problem},\text{method},\text{seed})\), five seeds, four trainable
hidden layers, paired per-seed collocation points, and a fixed held-out
evaluation set.  Every method is matched to the real trainable-parameter
budget of the width-128 complex \(\sinh\) network.  Width-64 experiments are
excluded because a smaller network completes more optimizer steps within a
fixed wall-clock budget, confounding architecture and throughput.

The four methods receive the same interior and boundary points for a given
seed.  Results must record the protocol identifier, Git commit, hardware,
actual hidden width, real trainable degrees of freedom, representation,
frequency parameters, optimizer settings, number of completed steps, and
evaluation-set definition.

\paragraph{Derivative backend.}
All compatible architectures use the same complex-Waring Taylor-jet
implementation.  A baseline-specific scaled activation or input embedding is
admitted only after its input derivatives and parameter gradients agree with
direct automatic differentiation.

\paragraph{Metric.}
Accuracy is the held-out relative \(L^2\) error
\begin{equation}
  \mathcal{E}_{L^2}
  =
  \frac{\lVert u_\theta-u_\star\rVert_{L^2(\Omega)}}
       {\lVert u_\star\rVert_{L^2(\Omega)}}.
\end{equation}
No numerical value is reported until all five seeds for the corresponding
atomic task pass the result validator.

\subsection{Polyharmonic benchmark}
\label{sec:bm:poly}

For \(d\in\{2,3\}\), let
\begin{equation}
  u_\star(x)=\prod_{j=1}^{d}\sin(\pi x_j),
  \qquad
  \Delta^m u_\star=(-d\pi^2)^m u_\star
  \quad\text{in }(-1,1)^d.
\end{equation}
We use orders \(2m\in\{2,4,6\}\) and Navier boundary conditions
\(\Delta^j u=0\), \(j=0,\ldots,m-1\).  The multidimensional frequency
parameters are \(\omega_0=2\pi\) and \(\sigma=\pi\).

Each pair \((d,2m)\) is an independent atomic task.  In particular,
\((d,2m)=(3,6)\) is part of the preregistered main grid rather than an
outcome-dependent optional experiment.

\subsection{Non-separable radial chirp}
\label{sec:bm:chirp}

On \((-1,1)^2\), define
\begin{equation}
  u_\star(x,y)
  =
  \sin\!\left(\frac{a\pi}{2}(x^2+y^2)\right),
  \qquad
  -\Delta u+u=f,
\end{equation}
with Dirichlet data from \(u_\star\).  The preregistered sweep is
\(a\in\{1,2,3\}\).  Each \(a\) is an independent atomic task.

\subsection{Time-harmonic Maxwell benchmark}
\label{sec:bm:maxwell}

The two-dimensional transverse-magnetic problem is represented by
\begin{equation}
  \Delta E+\kappa^2E=f,
  \qquad
  \kappa^2=(a\pi)^2(1+\mathrm{i}\beta),
  \qquad
  E_\star=\exp\!\bigl(\mathrm{i}a\pi(x+y)\bigr),
\end{equation}
with \(\beta=0.2\), exact Dirichlet data, and
\(a\in\{2,4,6\}\).  Complex \(\sinh\) represents \(E\) natively; each real
baseline uses a split real--imaginary pair whose total trainable-parameter
budget is matched to the native complex model.  Each \(a\) is an independent
atomic task.

\subsection{Result-generation contract}

The runners do not commit or push.  Each atomic task writes an isolated result
bundle and history sidecar.  The validator checks method coverage, five unique
seeds, metadata, finite metrics, and protocol consistency before bundles may be
merged into canonical tables.  Figures and tables are generated only from
validated \texttt{jsc\_v2} bundles.
